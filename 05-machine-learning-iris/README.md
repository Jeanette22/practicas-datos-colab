## Objetivo
Primeros pasos en Machine Learning con el clásico dataset **Iris** de scikit-learn.

## Temas
- Carga del dataset con `load_iris`
- Exploración visual: gráficos de dispersión (`scatter`) y `pairplot`
- Separación en entrenamiento y test (`train_test_split`)
- Entrenamiento de modelos: **KNN** y **árbol de decisión**
- Hiperparámetros, predicción e interpretación
- Evaluación: `accuracy_score` y matriz de confusión

## Librerías
`scikit-learn` · `pandas` · `numpy` · `matplotlib` · `seaborn`

## Nota
El notebook usa `plot_confusion_matrix`, función eliminada en scikit-learn ≥ 1.2. Con versiones recientes se reemplaza por `ConfusionMatrixDisplay`.
