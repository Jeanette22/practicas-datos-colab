## Objetivo
Crear una conexión a una base de datos SQL desde Python y consultar sus tablas.

## Base de datos
`classic_rock.db` (SQLite), leída desde Google Drive (no incluida en el repo). Se trabaja con la tabla `rock_songs`.

## Temas
- Conexión a una base SQLite con `sqlite3`
- Listado de las tablas de la base
- Lectura de una tabla en un DataFrame de pandas

## Librerías
`sqlite3` · `pandas`
