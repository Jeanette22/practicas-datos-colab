## Objetivo
Preparar un dataset real para el análisis: carga, limpieza, estandarización, revisión y análisis exploratorio.

## Dataset
Turismo emisivo (turistas residentes), publicado por el Ministerio de Turismo de Argentina: <http://datos.yvera.tur.ar/dataset/turismo-emisivo>.
El notebook lee el archivo `turistas-residentes-serie.csv` desde Google Drive (no incluido en el repo).

## Temas
- Carga de datos con pandas
- Cambio de formato de fechas
- Estandarización y revisión del dataset
- Estadísticas descriptivas (promedio, mínimos, máximos)
- Gráficos de los países más visitados por residentes de Argentina

## Librerías
`pandas` · `numpy` · `matplotlib` · `datetime`
