Cada carpeta tiene su propio `README.md` con el objetivo, los temas y las librerías del notebook.

## 🚀 Cómo usarlos

1. Haz clic en el botón **Open in Colab** del proyecto que quieras ver.
2. Algunos notebooks leen archivos desde Google Drive (`/content/drive/MyDrive/...`). Los datasets **no están incluidos** en el repo: cada README indica cuál se usa y de dónde obtenerlo.
3. Para ejecutarlos en local: `pip install -r requirements.txt`.
