## Objetivo
Práctica de manejo de datos con pandas realizada en la "Escuela de Datos".

## Datasets
- `saldo-turistas-serie.csv` (desde Google Drive, no incluido en el repo)
- Star Wars: <https://raw.githubusercontent.com/pablo14/datasets/main/star_wars/starwars.csv>

## Temas
- Eliminar columnas y **eliminar / identificar duplicados**
- Ordenar un DataFrame (una y dos columnas)
- Crear, reordenar y renombrar variables; limpiar espacios en columnas
- Filtrar datos con `query`
- Estructuras de control: `if`, `while`, `for`
- Desarrollo de funciones y acceso a arrays
- Trabajo con directorios (`os`)
- Perfilado de datos (`funpymodeling`, `pandas-profiling`)

## Librerías
`pandas` · `numpy` · `os` · `funpymodeling` · `pandas-profiling`
